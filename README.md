# Repozytorium dodatków Home Assistant

Repozytorium do dodania w Supervisorze: **Ustawienia → Dodatki → Sklep z
dodatkami → ⋮ → Repozytoria**, wklej:

```
https://github.com/dawidf/trash-taken-checker
```

Po odświeżeniu w sklepie pojawi się dodatek opisany w
[`trash_taken_checker/README.md`](trash_taken_checker/README.md).

## Dodatki

- [**Harmonogram wywozu śmieci**](trash_taken_checker/) — pobiera
  harmonogram wywozu odpadów (ZGK Sułkowice) i dodaje terminy do
  kalendarzy Home Assistant.
